STUDY IMAGE EDITOR V5
Features:
- Background removal by connected region or optional global matching colour (includes enclosed holes inside letters).
- Smooth chroma-aware neutral colour inversion to reduce anti-aliased coloured fringes.
- Optional gentle edge enhancement and 2x high-quality resampling.
- Undo/redo/reset, drag-drop/paste, zoom/scroll and transparent PNG export.

For enclosed counters in letters, enable "Remove matching colour everywhere" and use a low tolerance. This removes matching pixels across the image, so matching-colour details elsewhere may also become transparent.
Quality enhancement and 2x resampling improve appearance but cannot recreate details absent from the source.

Install: Upload all package contents to a GitHub repository root, enable Settings > Pages > Deploy from a branch > main > /(root), open the HTTPS URL once in Chrome Android, then choose Install app.
