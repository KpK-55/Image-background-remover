STUDY IMAGE EDITOR V4
This version intentionally keeps only:
- Background remover (click-to-remove and brush-to-remove)
- Colour inverter (neutral tones invert; coloured image parts retain colour identity)
- Import/paste/drag-drop, undo/redo/reset, zoom/scroll and transparent PNG export as supporting workflow controls.

Removed: text/label recolouring, text cleanup, erase/restore manual refinement, brightness/contrast/sharpening, upscaling.

Publish all package contents to a GitHub repository root. Enable Settings > Pages > Deploy from branch > main > /(root). Open the HTTPS site in Chrome Android once online, then Chrome menu > Install app. After first successful load, the app shell is cached for offline use.
