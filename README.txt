STUDY IMAGE EDITOR V3
Upload all files/folders to the root of a GitHub repository and enable Settings > Pages > Deploy from branch > main > /(root).
Open the resulting HTTPS site once online in Chrome Android, then menu > Install app.
V3 label recolouring: choose target Star Note background; choose source label appearance (light-on-dark or dark-on-light); choose Label-only text colour; paint over label and its local background only. This changes neutral pixels inside the brush footprint only. The central diagram outside the brushed label regions is not globally altered. Use Undo if the brush crosses a diagram feature.
