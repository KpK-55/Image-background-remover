STUDY IMAGE EDITOR V6
New:
- Eraser brush: select Eraser and paint over unwanted labels or any image area; transparent PNG result.
- Trim halo: gently reduces alpha on semi-transparent pixels touching transparency.
- Text thickening: expands visible pixels into nearby transparent pixels; use small radius to avoid merging close labels.
- Sharpening, contrast and brightness adjustments.
- Compact responsive UI.

Existing:
- Click/brush background removal, global colour matching for enclosed counters, fine detail protection.
- Smooth selective neutral inversion while retaining colour identity.
- Undo/redo/reset, drag-drop/paste, zoom/scroll, PNG export.

All edits are local in the browser. Trim halo/text thickening are pixel operations and should be inspected at 100% zoom; use Undo if they affect fine adjacent details.
Install via GitHub Pages: upload all files to repo root, enable Settings > Pages > Deploy from branch > main > /(root), open HTTPS URL in Chrome Android once, then Install app.
